この Wiki の本文は **GitHub Flavored Markdown（GFM）** 互換の Markdown で書きます。左の「書き方」をそのまま本文に書くと、右のように表示されます。

関連: [MCPWiki の使い方](/wiki/help-wiki)

## 見出し

```markdown
# 見出し 1（記事タイトルに相当）
## 見出し 2
### 見出し 3
```

`#` の数で階層が決まります。`#` の後には半角スペースが必要です。

## 段落と改行

```markdown
1 行目
2 行目（空行がないと同じ段落になります）

空行を入れると新しい段落になります。
行末に半角スペースを 2 つ入れると、  
段落の中で改行できます。
```

## 文字の装飾

| 書き方 | 表示 |
|---|---|
| `**太字**` | **太字** |
| `*斜体*` | *斜体* |
| `~~取り消し線~~` | ~~取り消し線~~ |
| `` `コード` `` | `コード` |
| `***太字かつ斜体***` | ***太字かつ斜体*** |

## リンク

```markdown
[外部サイト](https://example.com)
https://example.com          ← URL はそのまま書いても自動でリンクになります
[Wiki の別の記事](/wiki/help-wiki)
```

[Wiki の別の記事](/wiki/help-wiki)

**Wiki の記事へのリンクは `[表示名](/wiki/記事ID)` と書いてください。** 記事 ID は記事の URL の `/wiki/` の後ろの部分です。この形式で書いたリンクは、記事の「関連グラフ」と、リンク先の「この記事へのリンク」に反映されます。

外部サイトへのリンクは新しいタブで開きます。

## 画像とファイル

編集画面の「画像・PDF を添付」ボタン、ドラッグ＆ドロップ、貼り付けで添付すると、次の形式の記法が自動で入ります。

```markdown
![説明](/wiki/記事ID/files/ファイルID)     ← 画像は本文の中に表示されます
[資料.pdf](/wiki/記事ID/files/ファイルID)  ← PDF はダウンロードのリンクになります
```

外部サイトの画像（`![](https://...)`）は、閲覧者を追跡されないよう表示しない設定にしています。画像は添付してください。

## 折りたたみ（HTML）

一部の HTML も使えます。

```html
<details>
<summary>クリックで開く</summary>

折りたたまれた本文です。

</details>
```

<details>
<summary>クリックで開く</summary>

折りたたまれた本文です。

</details>

スクリプト、スタイル、フォーム、`iframe` などは安全のため取り除かれます。

## 記号をそのまま表示する

Markdown の記号（`*`、`_`、`#`、`[` など）を文字として表示したいときは、前に `\` を付けます。

```markdown
\*これは斜体になりません\*
```

\*これは斜体になりません\*

## この Wiki で使えない記法

GitHub では使えても、この Wiki では表示されない記法があります。

| 記法 | 代わりの方法 |
|---|---|
| 脚注 `[^1]` | 本文中に（注: …）と書く、または記事の末尾に「注」の節を作る |
| 注意書き `> [!NOTE]` | `> **注意:** …` のように太字の引用で書く |
| 絵文字 `:smile:` | 絵文字（😀）を直接入力する |
| Mermaid の図 | 図を画像にして添付する |
| 数式 `$x^2$` | 数式を画像にして添付する、またはコードブロックで書く |
| 見出しへのリンク `#見出し` | 記事へのリンクを使う |
