MCPWiki は、人が Web 画面から、AI（LLM）が MCP から、スクリプトが CLI から、同じ記事を読み書きできる Wiki です。記事の書き方は [Markdown の書き方](/wiki/help-markdown) を見てください。

## ログイン

- 管理者から届く招待メールの仮パスワードで、初回のログインをします。
- 初回は、新しいパスワード（12 文字以上で、大文字・小文字・数字・記号をすべて含む）を設定し、認証アプリ（Google Authenticator、1Password など）に QR コードを登録します。
- 2 回目以降は、パスワードと認証アプリの 6 桁のコードでログインします。

## ロール（役割）

| ロール | できること |
|---|---|
| 閲覧者（viewer） | 読める記事の閲覧と検索 |
| 投稿者（editor） | 上記に加えて、記事の作成と、編集を許可された記事の編集 |
| 管理者（admin） | すべての記事の閲覧・編集・削除・復元、ユーザの招待とロールの変更、監査ログの閲覧、OKF の入出力 |

## 記事を書く

1. サイドバーの「新規作成」を押します。
2. タイトル、概要（1 文の要約）、タグ（カンマ区切り）を入れ、本文を Markdown で書きます。右側にプレビューが出ます。
3. 「閲覧」と「編集」の範囲を選び、「作成」を押します。

記事 ID は空欄にすると自動で決まります。半角英小文字、数字、`-` で自分で付けることもできます。ID は記事の URL になり、あとから変更できません。

### 閲覧と編集の範囲

| 設定 | 選択肢 |
|---|---|
| 閲覧 | 管理者のみ / オーナー（作成者）のみ / だれでも（ログインしている人全員） |
| 編集 | 読み取りのみ / 管理者のみ / オーナーのみ / 投稿者全員 |

- 編集の範囲を、閲覧の範囲より広くすることはできません。
- 読めない記事は、一覧、検索、タグ、グラフのどこにも表示されません。
- 範囲を広げる操作は Web 画面からだけ行えます（CLI と MCP では狭めることしかできません）。

### 同時に編集したとき

先に誰かが保存していた場合は、保存しようとするとエラーになります。内容を控えてから最新版を開き、変更を反映し直してください。

## タグ、リンク、グラフ

- **タグ:** 記事の分類です。サイドバーのタグや「タグ」ページから、同じタグの記事を一覧できます。
- **リンク:** 本文に `[表示名](/wiki/記事ID)` と書くと、記事同士がつながります。リンク先の記事の下には「この記事へのリンク」として表示されます。
- **関連グラフ:** 記事の「関連グラフ」で、リンクでつながった記事を図で見られます。「タグの関連も表示」を押すと、同じタグを持つ記事のつながりも表示されます。サイドバーの「グラフ」では Wiki 全体を見られます。

## 画像と PDF の添付

- 編集画面の「画像・PDF を添付」ボタン、ドラッグ＆ドロップ、スクリーンショットの貼り付けで添付できます。本文には自動で記法が入ります。
- 対応している形式は PNG、JPEG、GIF、WebP、PDF で、1 ファイル 10MB までです。
- 添付ファイルを見られる人は、記事を読める人と同じです。非公開の記事の添付は、URL を知っていても見られません。
- 記事を作成（保存）してから添付してください。

## 履歴とレビュー

- **履歴:** 記事の「履歴」から、過去の版の一覧と、各版の内容を見られます。
- **レビュー済みにする:** 内容を確認したら押します。誰がいつ確認したかが記録されます。内容が変わると、記録はリセットされます。
- **下書き:** AI（MCP）が作成した記事は「draft」として保存されます。内容を確認して、必要ならステータスを「stable」にしてください。

## 検索

- ヘッダーかサイドバーの検索欄に入力します。タイトル、タグ、概要、本文が検索の対象です。
- 複数の語を空白で区切ると、すべてを含む記事を探します。
- 日本語は 2 文字以上で検索してください。1 文字だけの検索や、英単語の一部での検索は、タイトル、概要、タグとだけ照合します。

## 削除

- 記事を削除できるのは、オーナーと管理者です。Web 画面からだけ削除できます。
- 削除した記事は、管理者が「管理」→「記事」→「削除済みの記事を表示」から復元できます。

## CLI（コマンドライン）

```bash
mcpwiki configure --env dev --url https://<この Wiki の URL>
mcpwiki login                 # ブラウザでサインイン（MFA）
mcpwiki list                  # 記事の一覧
mcpwiki search キーワード
mcpwiki get <記事ID>          # 記事を表示
mcpwiki create --title "タイトル" --tags a,b --file note.md
mcpwiki edit <記事ID>         # エディタで編集
mcpwiki attach <記事ID> 画像.png
mcpwiki help                  # コマンドの一覧
```

CLI のインストール方法は、リポジトリの README を見てください。

## AI（MCP）から使う

CLI でログインしておくと、AI のツールから MCP で Wiki を使えます。

**Claude Code**

```bash
claude mcp add --scope user mcpwiki -- mcpwiki mcp --env dev
```

**Kiro**（`~/.kiro/settings/mcp.json` の `mcpServers` に追加）

```json
"mcpwiki": {
  "command": "/usr/bin/node",
  "args": ["/home/<ユーザ名>/.local/bin/mcpwiki", "mcp", "--env", "dev"],
  "autoApprove": ["list_articles", "get_article", "search_articles", "list_tags", "get_graph", "get_backlinks"]
}
```

「MCPWiki で○○の記事を探して要約して」「今日の作業を MCPWiki の記事にまとめて」のように頼めます。AI は記事の検索、取得、作成、更新、グラフの取得、添付画像の参照ができます。削除と、閲覧・編集範囲を広げる操作はできません。

## そのほか

- **OKF でのエクスポート:** 管理者は「管理」→「OKF 入出力」から、記事を Open Knowledge Format のファイル群（ZIP）として出力・取り込みできます。CLI では `mcpwiki export` を使います。
- **困ったとき:** 管理者に連絡してください。
